# Ogu Language Bank (OLB)

Ogu Language Bank (OLB) is a Django-powered online dictionary designed to preserve, document, and promote the Ogu language. The platform allows users to search for Ogu words, learn their meanings, pronunciations, translations, and contribute new words for review.

## Features

- User authentication
- Search Ogu words
- English translations
- Word meanings
- Example sentences
- Pronunciations
- Categories
- Dialects
- Parts of speech
- Word of the Day
- Favorite words
- Word ratings
- Comments
- User word contributions
- Admin approval workflow
- Responsive interface

## Built With

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite (Development)

## Installation

Clone the repository:

git clone https://github.com/DeCatalyst247/OguLanguageBank.git
Navigate into the project:

cd OguLanguageBank
Create and activate a virtual environment.

Install dependencies:

pip install -r requirements.txt
Apply migrations:

python manage.py migrate
Run the development server:

python manage.py runserver
